# FormVox documentatie

Welkom bij de FormVox-documentatie. FormVox is een file-based formulieren- en polls-app voor Nextcloud die alles opslaat in `.fvform`-bestanden — geen database-tabellen nodig.

![FormVox-homepage](screenshots/Start.png)
